# selfplay

Self-play RL engine for Gen 9 Champions VGC. The battle engine is Rust, with
Python bindings via PyO3. Plan and status are in [DESIGN.md](DESIGN.md).

## Layout

- `engine/`: pure-Rust battle engine (crate `selfplay-engine`, lib `engine`).
- `pybind/`: PyO3 bindings, built into the Python module `selfplay._engine`.
- `python/selfplay/`: the Python package.
- `data/dex.json`: species, moves, natures and type chart, generated by
  `tools/gen_dex.py` from poke-env's bundled Showdown data and embedded in
  the engine at compile time.
- `tests/`: Python tests, including parity against `src/`.

## Build

Needs Rust (https://rustup.rs) and, on Windows, the MSVC C++ build tools.

    pip install maturin
    pip install ./selfplay          # or, inside a venv: cd selfplay && maturin develop --release

## Test

    cd selfplay && cargo test                    # Rust unit tests, no Python needed
    python -m pytest selfplay/tests              # parity tests (needs the build above)

## Regenerate the dex

    python selfplay/tools/gen_dex.py

Commit the resulting `data/dex.json` diff with the change that needed it.
